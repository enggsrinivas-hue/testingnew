SMS Buddy - get the APK with GitHub (no Android Studio)
1. Create a free GitHub account and a new PRIVATE repository.
2. Upload the CONTENTS of this folder (Add file > Upload files).
3. Add file > Create new file, name it:  .github/workflows/build.yml  and paste the workflow text, then Commit.
4. Open the Actions tab, wait ~5 min for a green tick, open the run, download "SmsBuddy-apk".
5. Unzip it, send app-debug.apk to your phone, tap it to install (allow "install unknown apps").
